HomeRPG ArchLord v0.3.3 — LISEZMOI pour les testeurs
====================================================

Merci de tester ! HomeRPG ArchLord fait tourner ArchLord en solo, hors ligne, sur votre PC :
un serveur ArchCore local, sa propre base MariaDB et le client ArchRust, lancés par un seul
bouton JOUER. Rien ne sort de votre PC (tout écoute sur 127.0.0.1).

Cette version : ArchCore 6b1bf96 (branche Core du 9 novembre 2026) avec le module ArchBot
(bots), ArchRust 5c96570 (9 novembre 2026), ArchCore Admin 1.4.0. Le monde fourni est
importé avec les quêtes, titres, maîtrises et la courbe d'expérience d'origine.

C'est la première version pour les essais EN JEU : tout le code a été vérifié au
simulateur, à vous de le jouer pour de vrai. Chaque retour compte.


1. CE QU'IL VOUS FAUT
---------------------

* Windows 10 ou 11, 64 bits, environ 2 Go libres (plus les données du jeu).
* Les données du jeu ArchLord 64 bits (dossiers character, ini, world, texture, object,
  effect, sound…). Si votre paquet de test ne les contient pas déjà dans Client\, prenez-les
  dans votre propre client ArchLord.
* Rien d'autre : les tables du serveur ArchLord d'origine (valeurs du jeu de l'épisode 8,
  apparitions des monstres, butin, IA, raffinage, carte) sont incluses dans
  Server\Data\server-ini\. Ne supprimez pas ce dossier : sans lui, le monde ne peut pas
  être importé.
* Les ports 3316, 11002 et 11008 doivent être libres (un autre serveur ArchLord éteint).


2. INSTALLATION
---------------

1. Décompressez le dossier dans un dossier où vous pouvez écrire (par exemple C:\Jeux\).
   Évitez « Program Files ».
2. Données du jeu, si elles ne sont pas déjà dans Client\, au choix :
   - copiez-les dans Client\, à côté d'ArchRust.exe ;
   - ou laissez-les où elles sont et indiquez leur dossier dans le launcher :
     Paramètres > « Données du jeu ArchLord ».
3. Ouvrez « HomeRPG ArchLord.exe ». Le launcher n'est pas signé : si Windows affiche
   « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires »
   puis « Exécuter quand même ».
4. Langue : le launcher s'ouvre en français si Windows est en français, sinon en anglais.
   Paramètres > « Langue du launcher » la change ; le jeu suit la même langue.


3. PREMIER LANCEMENT
--------------------

Cliquez sur JOUER. Le launcher enchaîne, en affichant chaque étape :
  1. démarrage de MariaDB (création de la base la première fois) ;
  2. mise à jour du schéma des bases (archcore db-init) ;
  3. import du monde : valeurs de l'épisode 8 depuis les tables du serveur d'origine, noms
     et visuels depuis vos données du jeu (archcore import) : environ une minute, une seule
     fois (et de nouveau après une mise à jour d'ArchCore) ;
  4. écriture des tables de l'épisode 8 pour ArchRust dans Client\server-data (archcore
     export-client-tables) : les infobulles, prix et conditions affichés par le jeu sont
     ceux du serveur ;
  5. démarrage du serveur ArchCore, avec ses bots ;
  6. ouverture d'ArchRust, déjà réglé sur le serveur local et dans la langue choisie.
Fermer ArchRust fait une sauvegarde automatique de vos personnages ; fermer le launcher
arrête le serveur et la base.


4. COMPTES DE TEST
------------------

Aucun compte n'existe au départ. Dans l'onglet Comptes du launcher, créez par exemple :
  * testeur  / test1234  niveau MJ 3 : toutes les commandes de maître du jeu, le panneau
    ArchCore Admin dans le jeu (/aca) et les commandes MJ des bots ;
  * joueur   / test1234  niveau MJ 0 : un joueur normal.
Identifiant : 1 à 16 lettres ou chiffres ; mot de passe : 4 à 16 caractères sans espace.
Dans ArchRust, connectez-vous sur le panneau de connexion d'ArchRust (identifiant et mot
de passe ; le serveur local est déjà rempli). Cochez « Enregistrer le compte » pour ne plus
avoir à le saisir. Les comptes archbot_… sont ceux des bots : le launcher
les masque, n'y touchez pas.


5. VOUS AVIEZ UNE VERSION PRÉCÉDENTE ?
--------------------------------------

Depuis la v0.3.2, la v0.3.1 ou avant : deux possibilités.
  * Pour les quêtes, titres, maîtrises et l'expérience d'origine (conseillé) : gardez le
    UserData\ fourni avec la v0.3.3 ; vos anciens personnages ne sont pas repris.
  * Pour garder vos personnages : copiez votre ancien UserData\ dans la nouvelle version ;
    le monde est alors réimporté SANS les données d'origine de Webzen (quêtes, titres,
    maîtrises et expérience du client, comme en v0.3.1, et sans les quêtes des objets).

Depuis la v0.3.0 : launcher fermé, copiez le dossier UserData\ de l'ancienne version dans
la nouvelle. Au premier JOUER, le launcher ajoute la table du Gacha, réimporte le monde,
contrôle les bases (archcore db-check) et réécrit Client\server-data ; comptes,
personnages et bots sont conservés.

Depuis la v0.2.0 : launcher fermé, copiez le dossier UserData\ de l'ancienne version dans la nouvelle
(comptes, personnages, réglages, sauvegardes). Copiez aussi vos données du jeu (Client\) si
vous les aviez mises là et que le nouveau paquet ne les contient pas.
Au premier JOUER, le launcher applique les migrations des bases, réimporte le monde aux
valeurs de l'épisode 8, puis met vos personnages aux mêmes valeurs (archcore migrate-ep8),
une seule fois, après une sauvegarde « avant-ep8 » (onglet Sauvegardes) : les objets, options
et compétences propres à Archonia sont mis de côté (rien n'est détruit, l'opération est
réversible) et l'oubli des compétences vous est offert, leurs coûts ayant changé.

7. PROBLÈMES CONNUS
-------------------

* N'utilisez pas Monde > « Réimporter la base monde » : sans les données de Webzen (non
  fournies), le monde reviendrait aux quêtes, titres, maîtrises et à l'expérience du
  client ; le launcher le signale s'il le fait.
* Les noms de modèles des bots apparaissent en coréen dans le journal du serveur : c'est
  seulement le journal.
* Les bots ne font pas encore : achats, quêtes, combat entre joueurs, montures, guildes,
  soins des alliés.


8. LES JOURNAUX À NOUS RENVOYER
-------------------------------

Le plus simple : onglet Sauvegardes > « Exporter un diagnostic ». Le launcher crée
UserData\diagnostic-<date>.zip (journaux récents du launcher, du serveur, du client et de
MariaDB, configurations, mots de passe masqués) et ouvre son dossier. Envoyez ce fichier.

Sinon, les journaux sont dans Logs\ :
  * Logs\launcher.log            le launcher (étapes, erreurs) ;
  * Logs\server\archcore-*.log   le serveur ArchCore, un fichier par démarrage (lignes
                                 [archbot] pour les bots) ;
  * Logs\server\outils-*.log     l'initialisation, l'import du monde, l'export des tables ;
  * Logs\client\archrust-*.log   le client ArchRust, un fichier par partie ;
  * Logs\mariadb-error.log       la base de données.
Ils sont aussi visibles dans l'onglet Journaux du launcher.

Avec les journaux, dites-nous : ce que vous faisiez, ce que vous attendiez, ce qui s'est
passé, l'heure approximative et le nom du personnage. Une capture d'écran aide beaucoup.


9. BON À SAVOIR
---------------

* Tout reste dans le dossier : supprimez-le pour tout désinstaller. Gardez UserData\ si
  vous voulez garder vos personnages.
* Onglet Sauvegardes : sauvegarder et restaurer vos personnages.
* Un souci de démarrage ? Onglet Accueil > Vérifier, puis Réparer.
* Onglet Monde > « Réimporter la base monde » : refait l'import (comptes et personnages
  conservés) ; à éviter dans cette version, voir PROBLÈMES CONNUS.
* Ne modifiez pas Client\server-data ni Client\realmlist.wtf : le launcher les écrit.
