HomeRPG ArchLord — single-player, offline ArchLord
===================================================

(Français : voir LISEZMOI.txt)

1. Put your ArchRust client in the Client\ folder: ArchRust.exe and, next to it,
   the 64-bit ArchLord game data (character\, ini\, world\, texture\…).
   Or set its location in Settings. The client is not included.

2. Optional: the original ArchLord server tables (monster spawns, loot) in
   Server\Data\server-ini\. Without them, the world has no monsters or loot.

3. Open "HomeRPG ArchLord.exe" and click PLAY.
   The first start imports the world from your client (a few minutes, only once).

4. Create your account in the Accounts tab (GM level 3 for every command),
   then log in with it in ArchRust.

Everything runs on this PC (127.0.0.1), with no Internet connection.
Your accounts, characters, settings and backups are in UserData\: keep this folder.
Logs: Logs\ (launcher, server, client), and the launcher's Logs tab.
The launcher language is set in Settings (French or English).
