# Server/Config

Configurations générées par le launcher à chaque démarrage, jamais versionnées :

- `auth.conf`, `world.conf` : configuration d'ArchCore (`ARCHCORE_CONF_DIR`), écrites depuis les modèles
  `Server/ArchCore/config/*.dist` ; clés gérées (écoute sur 127.0.0.1, ports, base, chemin du client) puis
  réglages de l'onglet Monde.
- `my.ini` : MariaDB portable (127.0.0.1:3316, données dans `UserData/Database`).

Ne pas les modifier à la main : changer les réglages dans le launcher (ou `Launcher/src/server.rs`).

Generated by the launcher at every start, never versioned. Do not edit by hand: use the launcher settings.
